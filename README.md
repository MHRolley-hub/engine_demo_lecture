# APEX Driver Lab 3

**Beat the AI Racing Driver** — an interactive game for an Engineering Speed university taster lecture.

## Play online

Once GitHub Pages is enabled, open: https://mhrolley-hub.github.io/engine_demo_lecture/

## Enable GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, with **main** and **/(root)**, then Save.

## Game

The full game is contained in [`index.html`](index.html), including embedded road images, styles and JavaScript. No build step or server is required. Features include Learner / Experienced / Racecar AI, short / medium / long races, driving-condition voice prompts (browser TTS), sensor faults, timed bonuses and victory confetti.

For local use, download `index.html` and open it in Chrome or Edge. Text-to-speech depends on available browser and operating-system voices.
